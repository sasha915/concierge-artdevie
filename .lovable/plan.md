# Extension desktop des écrans principaux

## Objectif
Adapter Mes demandes, Offres et Membership au grand écran à partir de 1024 px, en conservant strictement les vues mobiles existantes et les données réelles.

## Modifications prévues
- **Mes demandes** : réunir le titre, le sous-titre et le bouton de création sur une ligne en desktop ; conserver les filtres dessous ; afficher les demandes sur trois colonnes.
- **Offres** : réunir le titre et le sous-titre dans un en-tête desktop cohérent ; garder les filtres sur une ligne dédiée ; afficher les offres sur trois colonnes.
- **Membership** : garder le titre sur toute la largeur, puis créer une grille desktop avec la carte et le bouton WhatsApp à gauche, le menu et la citation à droite.
- Conserver sans changement les structures actuelles sous 1024 px.

## Détails techniques
- Utiliser uniquement les variantes responsives `lg:` dans les trois écrans existants.
- Réutiliser les composants, couleurs, rayons et données déjà en place.
- Vérifier les trois pages à 1280 px et contrôler les mêmes pages à 390 px, avec inspection des erreurs d’affichage et de console.
